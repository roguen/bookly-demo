# Deck generator

`Bookly_Agent_Architecture.pptx` in the repo root is generated by
`build.js`, not hand-edited. To rebuild it:

```bash
cd deck && npm install && npm run build
```

That writes `../Bookly_Agent_Architecture.pptx`, including all speaker
notes.

**This is build tooling only.** The agent itself still runs with no
dependencies and no API key — `npm` is never needed to run the demo or the
tests. Nothing under `deck/` is imported by any Python module.

Every transcript excerpt on the slides is copied verbatim from
`../evidence/`, with elisions marked `...`. If you change the evidence,
re-check the slide text against it.
